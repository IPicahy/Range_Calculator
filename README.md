# Баллистический калькулятор MOA 

Простая и удобная программа с графическим интерфейсом для расчета поправок оптического прицела (в MOA) в зависимости от дистанции. Построена на базе Python и библиотеки `customtkinter` для современного внешнего вида.

## Основные возможности

* **Управление профилями:** Создание, сохранение и удаление профилей для разного оружия или патронов (данные сохраняются локально в файл `ballistic_profiles.json`).
* **Интеллектуальный расчет:** Автоматическая интерполяция и экстраполяция (с предупреждением) поправок для любой введенной дистанции на основе ваших базовых точек.
* **Генерация баллистической таблицы:** Создание подробной таблицы с шагом 50 метров и удобной кнопкой **быстрого копирования в буфер обмена** для переноса в Excel, блокнот или мессенджеры.
* **Калибровка нуля:** Быстрая корректировка смещения прицела (запас или клики вверх) без изменения базовой таблицы.
* **Кастомизация интерфейса:** Несколько визуальных тем, включая темную, светлую и стильную полупрозрачную (с использованием `pywinstyles`).

## Как запустить

### Шаг 1. Предварительные требования
Убедитесь, что на вашем компьютере установлен **Python** (рекомендуется версия 3.8 или выше). Скачать его можно с [официального сайта](https://www.python.org/downloads/).

### Шаг 2. Установка зависимостей
Программе требуются дополнительные библиотеки для отрисовки интерфейса. Откройте терминал (или командную строку) в папке с вашим проектом и выполните команду:

```bash
pip install customtkinter pywinstyles
```

### Шаг 3. Запуск программы
## После установки зависимостей просто запустите основной файл скрипта:
```bash
python Ballistic_calc.py
```
### Использование
1. При первом запуске автоматически создастся дефолтный профиль .338 LM.

2. Добавьте свои проверенные дистанции и поправки (MOA) через меню "▶ Добавить точку".

3. Для редактирования или удаления существующих точек нажмите Правую Кнопку Мыши по нужной строке в таблице.

4. Используйте блок "Быстрый расчет", чтобы узнать точный клик для конкретной дистанции прямо на стрельбище.
